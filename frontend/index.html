Praxis

A web learning app for programming

Welcome!

Hello user, welcome to Praxis, your personal learning app for programming. Its job is to teach you specific programming concepts using a Socratic teaching model: A method of instruction where the student discovers the answers themselves!

Start by chatting with the chatbot to determine what you want to learn, and once it gets a clear picture of what you want to learn, it will start generating you a detailed and engaging story-based problem set complete with descriptions and skeleton code.

Reminder: This tool is meant to help you practice or learn programming CONCEPTS, it is not a chatbot to write your code for you, or answer your programming questions.
